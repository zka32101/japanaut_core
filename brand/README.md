# Showglobe シリーズ アイコン仕様（案）

国別アプリ（Showglobe Japan / Korea / …）のアイコンを、同じ形で量産するための取り決め。
生成: `python3 tools/gen_icons.py OUT_DIR`（`icon_<cc>.svg` 1024px と `sheet.svg`）。PNG は `chromium --screenshot` などで書き出す。

## 全アプリ共通（変えない）
- 角丸の外形、金属調の二重枠（外: 斜めの光沢 / 内: 細線）、地球儀グリッドの背景、上部のうっすらした光沢。
- 右下: 地球儀バッジ（立体、縁は金属リング）。
- 左下: 国コードのプレート（ISO 3166 の2文字。言語コード JA/EN は使わない）。

## 国ごとに変える
- 背景 = 国旗の主色、内側の線 = 副色、コード文字・バッジ線 = 主色の濃色。
- 中央の絵 = 国の象徴（日本は赤い鳥居）。必要なら背景に国旗由来の模様（豪州: 南十字星、英国: ユニオンジャック）。

## 注意
- `icons/` は確認用の下絵。ストア提出用は、フルブリード（角丸なし）の正方形・アルファなしで書き出し直すこと（Play は端末側でマスクする）。
- 48px では国コードが読みにくい。国の識別は色が主、コードは補助。
- 日本・エジプトは赤、韓国・フランスは青、豪州・英国は紺で近い。中央の絵・コード・背景模様で区別する。
- 宗教・政治に関わる象徴は審査・クレームの原因になりうる。観光名所を中心にする。
- 中央の絵は簡略化した下絵。実際の採用前に、各国に詳しい人・デザイナーの確認を受ける。

## アプリ内の共通テーマ（案）
`brand/theme/board.png`（元: `board.svg`、生成: `tools/gen_theme_board.py`）。

- **背景**: A 和紙＋朱の極薄グリッド（通常）/ B 藍の夜空＋地球儀（ダーク）/ C 朱グラデのヘッダー（下端を曲線に）。
- **アイコン**: 線画（太さ2・角丸）で統一。強調したい場所だけ立体チップ（朱の球＋白抜きアイコン）。
- **部品**: ボタン（朱の立体／白縁）、カテゴリのチップ、レベル・ストリークのバッジ、空の状態（グリッド＋立体チップ）。
- **ルール**: 影は柔らかく1段、縁は白の細線、文字の最小サイズは12px、各国版は主色・副色・モチーフだけ差し替え。
- パレット（日本版）: 朱 `#BC002D` / 濃朱 `#7E0020` / 明朱 `#E0334F` / 桜 `#FFB7C5` / 藍 `#3D405B` / 和紙 `#F7F4EF` / 墨 `#1D1D1D` / 金 `#C9A227`。
